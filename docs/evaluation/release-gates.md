2026-10-26用户明确由其本人在审阅页操作。已准备固定两题真实报告及本机来源导航/账号（`output/m6-08/review-r2/`，不上传）；每题分别选择第一、二轮保存，不能为了冻结门槛将未知改成通过。澄清结果显示“请求确认设备型号，未生成答案”，仍须人工判断该行为是否合理，不因空正文自动当作事实准确。旧准备时点真人审阅为0；后续045本人两轮已保存（含unknown），新隔离001尚无human审阅，详见[M6-08接续记录](../development/records/M6-08.md)。

从实验详情进入“审阅答案与质量门槛”。每条审阅绑定服务端题级结果的完整规范 JSON SHA256（问题、结果、来源、状态、指标），结果改变后旧分失效。四个维度分别记录 0（错误）、1（部分支持）、2（完整支持）、unknown（无法核对）或 not_applicable（不适用并在理由说明）；事实维度不能不适用，含图像来源的结果不能跳过图片审核。未知不是零分，不进入通过结论。

审阅身份 human/assistant/model 独立保留。reviewer_id 由当前登录账号授予，客户端不能冒填另一账号；human 必须由实际人工本人勾选已核对原件及身份声明。账号声明不等于系统自动认证“人类”，执行助手和模型不得选择 human。需要一、二两轮独立记录，同一人分轮或两人各负责一轮；同一结果/账号/身份/轮次不可覆盖。重复客户端请求返回原记录，内容改变返回409。分歧采用两轮最低分，未知或适用范围分歧待审。

基线所有题完成两轮人工核对、无关键错误及未知后，维护者可 POST /experiments/{id}/calibrations 冻结校准：题集/划分、全部题目与结果指纹、审阅ID、逐题分维最低分和说明，容差固定0。这是预先在基线上校准的保守非劣化门槛，不能观察候选后调低阈值。候选必须在校准后创建，完成同题集同划分同题集合，不允许只挑有利题。基线后续新增审核或结果改变使校准待审，须先重新校准再创建新候选；不能覆盖旧记录。

GET /experiments/{id}/release-gate?calibration_id=... 读取双方当前结果并复核校准。越权或错误型号任何一项关键错误直接 blocked；任一适用维度相对基线降低直接 blocked；缺人工、未知、内容/适用范围改变或实验范围不一致为 pending；全部满足才 passed。返回逐题退化维度、原因、人工记录数和 automatic_publish=false。passed 仅表示该固定报告符合门槛，不代表生产灾备、知识发布、总控阶段通过或授权进入M7。

当前门槛要求全题双轮，是保守默认；固定报告人工抽检单列抽样范围和未审题，不能以抽检冒称全量门槛通过。已有045本人双轮记录（含unknown），尚未完成固定报告的完整人工验收或校准，不报告答案质量提升。fresh heldout 冻结不运行、不用于阈值或策略选择。
