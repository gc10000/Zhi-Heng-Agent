# 技术支持流程：操作、恢复与边界

适用M5本机工作台。M6与服务器部署未授权；官方网页MCP延期、默认不注册外网工具。

在已完成问答下选择“进入支持流程与处理草稿”。确认实际知道的设备、现象，环境和错误码不清楚可留未知。当前只询问一个必要槽位，最多三轮补充，无进展或没有可追溯证据时转交人工。

清单是引用原文摘录，保留完整前提与风险提示，尚未执行。由用户填写实际结果后记录“已试”或“无效”，记录服务器时间与用户自报来源；纠正追加原记录，不覆盖历史。当现有可追溯步骤全部无效时，停止重复建议并转交。系统不会远程操作设备。用户确认解决只是自报，不能当现场验证成功。

支持状态保存在会话单文档聚合。刷新页面恢复服务端快照；遇409先使用“刷新服务状态”，核对新版本再提交，不直接换版本数字重发。未提交的表单不等于已保存；草稿确认前必须先保存用户编辑，确认后冻结该版本。

清空文本框不会静默撤回已确认事实；页面会提示使用对应字段的“设为未知”。API以`clear_slots`显式撤回、保留旧history和撤回时间，当前值及确认来源改为未知并递增上下文版本。有既有引用时需用新问答取得证据；旧run及已保存草稿快照不改写。遇版本冲突先刷新并重新确认操作。

更正已确认型号或环境后，旧证据不能继续生成新清单，应回到问答取得新证据。新运行冻结确认槽位及最新自报结果；旧run/消息/已确认处理记录保留当时快照。已准备但未领取的运行如遇上下文变化拒绝领取，需要新请求标识；不要改写原运行。取消或解决的支持流程不会被迟到响应重新启用；可从新会话开始。

如果服务恰在`active_run_id`已写入、run.claim_state从preparing改为claimed之前退出，恢复实例根据占用指针匹配该run，以冻结的旧快照完成claimed和用户消息幂等补偿；上下文纠正不应使这个已占用run永久卡死。尚未占用的准备run仍受版本门禁；pending超时不能因409被跳过，过期后标记interrupted。release只能清理自身run_id的占用。重复执行恢复扫描安全，不重新运行模型。不要手动清除占用、改写快照或给run改版本。

归档中的会话不再接受领取或恢复。若归档发生在占用CAS之后，`reconcile`按run版本CAS将该运行置为`interrupted`并标记`conversation_archived`，只释放仍指向该run的`active_run_id`；迟到worker不能删除新run的占用。恢复扫描对归档条目采用同一终态补偿后继续处理其他账本，重复扫描幂等，不捕获`RecursionError`掩盖状态错误。

归档worker如果先于扫描启动，也必须由`EventLedger`一次CAS写入`run.interrupted`、`seq`和outbox，再由幂等flush投递；看到版本冲突时核对同一run的事件是否已存在，不能仅凭终态字段假定可重放。公开事件读取应能看到一个`run.interrupted`，重复启动/恢复不得增加第二个终态事件。

设备槽位使用`clear_slots=['device']`撤回后，支持快照带有`subject_withdrawn`未来主体边界。没有本轮显式型号时，查询计划必须澄清，不能读取旧助手快照、会话旧选择或目录唯一项；用户明确提供并确认新型号后才可重新生成问答。旧消息、旧run和草稿快照保留原状。

升级兼容：旧快照若没有`subject_withdrawn`，仍可依据设备槽位为`value=null/confirmed=false/source=unknown`且含`withdrawn_by`，或历史`withdrawal.slots`包含`device`识别撤回；普通从未填写的未知设备没有这些撤回事实，不得重置。撤回后的显式产品选择来自当前run，清空旧历史但保留该选择；确认恢复后再继续使用本轮快照。

只读工具仅支持查授权产品、读本流程引用和按后端授予范围扩展检索内部手册。最多6次调用、其中2次扩展检索、30秒累计处理和12000 UTF-8字节保守token预算，不包括等待用户的时间。失败、重复或预算耗尽转交。超时是结果接纳门禁，不能保证同步模型或数据库硬中断。预留调用先落库，若进程在预留后退出，刷新可看到待核对状态；禁止手工清除字段重新派发，选择结束或转交，保留账本供审查。最多两个在途执行槽，晚到结果不得覆盖取消或纠正后的版本。

处理草稿包含本轮问题、资料修订、支持上下文及操作自报快照。重复生成同run返回原稿，保留用户编辑。确认与导出均检查owner/kb和精确资料修订，撤权后拒绝暴露嵌套快照或导出。转交仅生成草稿，不自动发送给他人。导出Markdown动态内容已转义，文中操作事实仍以用户自报为准。分类反馈只入待审账本，不会自动发布知识。

数据回滚：撤回`app/support/api.py`路由、问答支持快照消费者及Vue处理记录入口即可关闭新功能；保留`conversations.support`、`support_cases`、`support_feedback`及运行快照，不清库、不删除知识或对象。原问答和资料入口可继续使用。运行恢复仍按[任务恢复手册](worker-recovery.md)，支持流程不重放设备操作。

阶段真实验证使用新随机`m1_test_m5_live_*`账本，仅只读复制既有独立M3供应商产物及知识登记，复用源隔离Milvus/MinIO做读取，不重导入、不发起索引/发布/清理。账号配置、trace、视频和输出含私有数据，保存在本机`output/`，禁止上传；复核后只停止本脚本创建的进程，保留账本。精确命令及失败/恢复记录见[M5-08](../development/records/M5-08.md)。
