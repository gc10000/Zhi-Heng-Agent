# M6 regression来源闭环实施计划

基线e76651f；按总控已确认方案顺序实施，不调用供应商，不改真实题集或质量记录。

1. 以隔离合成题集建立失败回归：完整标签独立审核、已有冻结题绑定及变化后派生版本。
2. 不可变来源记录绑定反馈审核、原Run快照、完整题目及审核、冻结文件；通过受控catalog解析，不接受客户端路径。
3. 服务端在创建、job及题级Run前重验，将来源hash加入请求、实验、运行配置及检查点；兼容无来源旧实验。
4. 独立regression证明接口复用ReviewService门槛，核验当前结果、覆盖、版本、来源及顺序，不复用revision发布证明。
5. 合成夹具验证拒绝、幂等、并发、跨库和失败恢复；生成契约及类型，维护交接并正常提交推送。

执行自验不等于独立复审或M6验收。真实human双轮与预校准依赖保持；四题对象/配件和四题召回另行挂账。
