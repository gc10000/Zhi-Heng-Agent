# M6-03 实验API、独立队列与结果对比

日期：2026-10-26。状态：执行自验完成；阶段仍执行中，未提交总控审查。M7未授权。

## 实现和行为

新增受控catalog、私有Mongo题集/任务/结果/预算账本、评测应用服务与统一API、Linux专用任务路由和Vue实验页面。浏览器只能选择服务端ID/版本，不能提供路径/标准答案/指标。维护者读取自己的题集/实验及当前知识范围；viewer拒绝。基线按同所有者、kb、题集版本/hash校验，逐题按稳定ID比较答案/状态，不宣称文本变化即质量提升。

排队先持久化派发意图，broker发送后确认，60秒未领取可重投；有效排队不因时间久丢预算。未形成任务的预留60秒后可回收，迟到插入无法领取。运行attempt/token/租约fencing，10秒心跳续120秒租约；旧worker不能发布新结果或释放新占用。结果按attempt保存，CAS发布可见指针；取消在题边界保留已完成结果。重试需维护权限、版本和可重试分类，复用成功题日志；失败正式run只有显式任务重试才建立新请求身份，重复恢复保持幂等。

M6完整问答适配器补上分阶段候选身份/来源：正式QueryRunner仅在显式评测标记下保存候选来源，原文不重复落盘；适配器映射原件hash/页/准确资产，交给指标运行器。候选池不把后续扩展来源冒称初召回。M4旧模式和公开问答快照保持兼容；错误安全字段增加code/retryable，不存异常正文。

Windows PowerShell、项目已有`.venv`与前端锁定依赖；未安装/升级依赖、模型或PyTorch/CUDA。Docker Server 29.5.2及已有Mongo/Redis在线。集成仅使用`M1_TEST_DB=m1_test_m4_m6_adapter`（每例随机子库）及传输探针全新随机`m1_test_m6_queue_...`；不清库、不修改课程资料/解析缓存/已入库知识。未访问真实Milvus/MinIO或供应商，heldout未运行。

Linux评测worker只消费独立评测队列并发送实验UUID到认证宿主，实际模型环境复用Windows。原Linux镜像不含本机模型/torch，不能直接在容器冒称模型版本相同，因此采用受控宿主执行，记录于ADR-058。独立队列/单并发预算不保证共享GPU没有竞争或生产时延；容量结论留后续实测。

- `repository-api-red.xml/.txt`：真实隔离Mongo 2失败/9通过，复现过期排队预算放入第二任务及旧worker覆盖新结果；分别按终态占用与attempt发布指针修复。
- `jobs-red.xml/.txt`：正式任务/派发入口尚缺时2失败/6通过，未用ImportError复现。
- `comparison-red.txt`：1失败/1通过，基线逐题数据未返回；补上同题身份比较。
- `query-adapter-red.txt`：正式QueryRunner入口1失败，完整问答缺分阶段候选来源；补投影，未注入标准答案。
- `explicit-retry-red.txt`：正式失败题显式重试仍重复读取失败run，1失败；增加显式重试请求身份，成功题/重复恢复不重复调用。
- `timeout-red.txt`：1失败，运行器未保存安全可重试分类；扩充code/retryable。旧严格错误对象测试同步断言完整新对象及不含private正文，没有削弱断言。
- `queue-budget-red.txt`：1失败，同名队列配置未拒绝；现明确拒绝M6_QUEUE_NAME与M2_QUEUE_NAME相同。
- `reservation-window-red.txt`：1失败，预算预留后未插入任务会永久占用；补期限回收。`backend-regression-r2`又揭示Mongo无时区返回和UTC比较错误，1失败/175通过；将无时区值按Mongo UTC处理后复验。
- `cancel-intent-red.txt`：补查过期取消任务重领后的终态，1失败，发现running状态会掩盖持久取消意图；终态CAS及运行器最后提交边界再次核验取消，不得误写completed。
- 前端`frontend-red.txt`为占位页3失败，截图/trace另存`frontend-red-artifacts/`。首绿2通过/1失败，题集选择定位不稳定；补明确可访问名称，原产物保存在`frontend-first-green-artifacts/`。第二次3通过。
- 真实传输`transport-r1`因探针问题文本重复而被题集校验正确拒绝，随后脚本取不存在实验ID报KeyError；这是脚本fixture/错误处理问题，不计业务红测。新探针问题加独立身份并先核验HTTP状态；原报告/现场未覆盖。
