# M6来源约束比较答复记录

日期：2026-11-02
分支：`codex/m6-source-bound-comparison`
实现起点：`03a48c2`

当前用户目标是为原048同类比较题提供完整结论，同时避免把客户端访问、管理连接和设备上联跨层拼接。实现采用默认关闭的 `comparison_answer_v1`：模型只选冻结来源帧；程序从原句帧派生保守类别，只比较双方各自唯一的设备上联介质证据，再生成确定性自然语言答复。

本轮总控复核新增发现CMP-R1：结果投影信任同一Run中可协调改写的 `query_plan` 与比较目标，删除proof并把route降成普通回答可绕过比较恢复验证。已按红绿补回归并修复：投影时用传入的冻结题目、产品选择和历史重新计算计划，对比持久route、产品ID、目标和目标原因。首次执行及完成检查点核验均传入原题。

复核还发现CMP-R2：选择schema强制至少一帧，无法表达目录存在但无相关证据。新增红测确认拒绝空数组后，放宽为允许空选择并更新提示词；程序返回双侧证据不足，不引用无关帧，proof可恢复重算。

最终验证范围与结果见[独立技术复核报告](../reviews/M6-comparison-answer-implementation-r1.md)和[脱敏验证摘要](../reviews/M6-comparison-answer-validation-r1.json)：1496离线单元/契约、7项当前比较Run随机隔离Mongo及267项保存输入回放断言通过。回放覆盖54个请求和25题/35个必要证据单元，只有合成帧选择；未创建正式Run或质量记录。

技术子项限于默认关闭比较路径，独立复核通过。真实048质量、模型选帧完整性和未覆盖语义仍未证明。M6保持5/7，M6-04保持已验收，M6-05缺反馈复评proof，M6-08缺有效候选质量与阶段证据；43题暂停，heldout未运行，M7未启动。下一步只有一个新身份的048条件性方案，尚无模型调用授权。
