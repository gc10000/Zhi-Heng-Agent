## 直接边界矩阵

| 边界 | 实际行为及自验 |
| --- | --- |
| 自由文本、JSON外解释、额外或重复字段 | 拒绝，不将自由答案包装成合格输出 |
| 引用0/越界/bool/string/重复/空编号 | 严格拒绝，不补造引用 |
| 原文、内容hash、跨度、连续编号、物理页 | 与当前输入核对；调用前重核冻结载荷，漂移拒绝 |
| 条件、否定、版本、unknown | 原段完整引用，不抽掉限制，不将connection自动分类成上联或unknown改成不支持 |
| 原文内指令、编号、代码、HTML、图片 | 动态长度文字围栏包住原段；通过既有CitationGuard/AnswerFilter，不执行资料内指令 |
| 流式核验、截断与失败 | 核验前不发原始JSON或错误正文；只发程序渲染结果；截断拒绝，保存失败材料 |
| 缓存旧答案 | 开启新模式必须有可重放证明，不能靠现成自由答案跳过 |
| 预算与必要证据 | 原source_relations为基线，矩阵只消费相同已选内容，不能挤出原证据或历史 |
| Run/checkpoint/outcome与恢复 | 策略沿归属身份绑定；raw selection及映射/答案hash入Run和结果，恢复重算，篡改不追加调用 |
| 正式错误与结算 | answer_binding_invalid可观测；沿原失败结算，不手改账户/槽/恢复状态 |
| 默认兼容 | 缺字段时无新结果字段；显式开启才改模板及生成协议 |
| 原失败048 | 旧自由答案会被拒绝；这不是新048答对 |
