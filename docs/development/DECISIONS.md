## ADR-016 · R3 历史JPEG元数据兼容与真实验收 · 2026-10-23

原图片题成功续验后，准确JPEG真实HTTP200/hash/解码均符合预期，但既有对象Content-Type为image/jpg，验收器与Pillow标准image/jpeg比较失败。选择仅将image/jpg归一为image/jpeg，再验证实际格式；不接受任意image/*互换。先红测1 failed/19 passed，修复并增加PNG伪装反例后21 passed。替代方案是修改对象元数据或再次推理，前者触及受保护数据且非必要，后者重复费用/写历史；因此用已保存助手正文SHA256唯一匹配原响应，核对原final图集合，再真实HTTP只读复核。共享检查条件全部保留，PNG冒充JPEG仍拒绝。

另起正常配置新进程，无诊断预热/线程覆盖，首次查询实际加载模型、调用图/仓储/云模型并检验唯一final与一次助手保存；只覆盖隔离数据名、日志关闭与禁止模型下载。一次成功满足本次冷启动验收，不解释为所有历史原生崩溃已根治或长期稳定。原43.085秒图片异常未复现，脱敏诊断包装未捕到新异常，不能倒推旧根因。影响M0-09、验收共享函数、2项测试、新复核/冷启动脚本与文档，无生产逻辑/依赖/配置变更。证据与精确命令见records/M0-09.md；回滚逐片对照r3-before，停用新脚本即可，不删数据。替代ADR-013/015中“待恢复待真实验收”的当前状态，保留其历史事实。

## ADR-010 · 旧 API 终态归外层 · 2026-10-22

## ADR-012 · M0-09 真实验收发现设备参数偏差 · 2026-10-22
